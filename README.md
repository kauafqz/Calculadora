# 🧮 Calculadora Web

Calculadora desenvolvida em sala de aula como exercício prático de **Desenvolvimento Front-end**, utilizando **HTML, CSS e JavaScript**.

## 📚 Sobre o projeto

Este projeto nasceu durante as aulas de Desenvolvimento Web, com o objetivo de colocar a teoria em prática: construir a interface de uma calculadora e implementar seu funcionamento com JavaScript.

A atividade me ajudou a entender como a estrutura da página, a estilização e a lógica trabalham juntas em uma aplicação web.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da página e dos elementos da calculadora.
- **CSS3** — estilização e organização visual da interface.
- **JavaScript** — interação com os botões e realização dos cálculos.

## ✨ Funcionalidades

- Realização de operações matemáticas básicas.
- Interface de calculadora construída com HTML e CSS.
- Interações e cálculos implementados com JavaScript.

## 📂 Estrutura do projeto

```text
Calculadora/
└── calculista/
    ├── index.html
    ├── style.css
    └── script.js
```

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Acesse a pasta `calculadora`.
3. Abra o arquivo `index.html` no navegador.

## 💡 Aprendizados

Durante o desenvolvimento em sala de aula, pratiquei:

- Estruturação de páginas com HTML.
- Estilização e organização de interfaces com CSS.
- Implementação da lógica de uma calculadora com JavaScript.
- Integração entre HTML, CSS e JavaScript.

## 🎯 Objetivo

Este projeto faz parte da minha jornada de aprendizado em **Desenvolvimento Web**. A proposta é fortalecer minha base por meio da prática e aplicar os conhecimentos adquiridos em sala de aula.
