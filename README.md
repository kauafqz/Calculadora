# Calculadora

Projeto de uma calculadora web desenvolvida em sala de aula como exercício prático de desenvolvimento Front-end.

## Sobre o projeto

A calculadora foi criada utilizando **HTML, CSS e JavaScript**, com o objetivo de praticar a construção de interfaces e a implementação de funcionalidades utilizando JavaScript.

## Tecnologias utilizadas

- **HTML5** — estrutura da página
- **CSS3** — estilização e organização da interface
- **JavaScript** — lógica e funcionamento da calculadora

## Estrutura do projeto

```
Calculadora/
└── calculadora/
    ├── index.html
    ├── style.css
    └── script.js
```

## Funcionalidades

- Realização de operações matemáticas básicas
- Interface de calculadora desenvolvida com HTML e CSS
- Interações e cálculos implementados com JavaScript

## Objetivo

Este projeto faz parte da minha jornada de aprendizado em **Desenvolvimento Web**, colocando em prática conceitos básicos de **HTML, CSS e JavaScript**.
